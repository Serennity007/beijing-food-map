3. **MapLibre 署名在抽屉全展开时仍会被盖住**：本轮把署名抬到了抽屉上沿，低/中档完全可见；抽屉拉到 82% 最高档时署名随之上移、仍位于抽屉之下（该档位下列表本身即为主体）。若要"任何档位署名可见"，需把署名移出画布（下一轮与 B2 一起做即可）。
4. **A3 的"连续快速输入"只做了代码审阅级确认**（沿用既有序号守卫 + 新状态机在同一 effect 内），未在浏览器逐帧演示连打场景；加载中保留旧结果的文案已实现并被观察到，未单独截图。
5. **环境伪影（不要误报）**：本机内嵌浏览器在标签页被节流时，CSS transition 与地图相机动画会冻结在中途（静态模式抽查时相机停在中途坐标即此原因）。真实浏览器中动画 180–350ms 正常完成；截图前注入了仅用于测量的 `.drawer{transition:none}`，未进入代码。详见 `docs/render-check/README.md`。
6. **公共底图瓦片不稳定**（外部）：验证期间 OpenFreeMap/CARTO 多次超时或返回 "API KEY REQUIRED" 水印图，重试/刷新后恢复。不阻塞演示，上台前需确认网络；高德 Key 仍缺（blockers 既有项）。
7. **本轮未做**（按第一轮范围刻意排除，非遗漏）：B2 详情页信息层级、B4 后台合并选店、B5 错误文案、第三批全部规则类问题（N2–N7）、依赖升级（O7）。第二轮建议按指导意见从 B2/B4 继续。
