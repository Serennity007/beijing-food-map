# 京城黔味地图 · 演示版

在北京地图上发现、记录和分享真正吃过的贵州菜与西南风味餐馆。

**这是可运行的演示版：仓库里只有前端构建产物，所有餐馆、评分、评论和图片均为合成测试数据，不代表任何真实商户，也不构成任何推荐。**

## 在线预览

<https://serennity007.github.io/beijing-food-map/>

## 本地打开

仓库内是 Vite 构建后的静态站点（`index.html` + `assets/`），没有前端源码，也不需要安装依赖。用任意静态服务器打开即可：

```bash
npx serve .
```

直接双击 `index.html` 会白屏——页面以 ES module 加载脚本，`file://` 协议下会被 CORS 拦掉。

## 数据说明

演示数据内置在打包后的 JS 里（`assets/index-*.js`），包含合成的店名、菜系标签、地址坐标与点评文本。`404.html` 与 `.nojekyll` 服务于 GitHub Pages 部署。
